## 1. Project Overview
Evaluated **10,500 marketing leads** across 10 campaigns and 6 digital channels to analyze conversion funnels, CAC, and ROAS.

*Dataset Note: Synthetic data created for portfolio and analytical demonstration purposes.*

---

## 2. Quick Start
```bash
git clone https://github.com/farjadzeya/marketing-campaign-conversion-analytics.git
cd marketing-campaign-conversion-analytics
pip install -r requirements.txt
python src/data_cleaning.py
python src/analysis.py
streamlit run dashboard/app.py
```

---

## 3. Key Findings
- **Total Leads:** 10,500 -> 414 Customers
- **Total Pipeline Revenue:** $5,194,949.55
- **Average CAC:** $545.89
- **Top Channel:** LinkedIn Ads (16.80x ROAS)
